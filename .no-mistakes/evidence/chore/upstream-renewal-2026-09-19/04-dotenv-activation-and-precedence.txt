SCENARIO: the captain stores the credential as a TYPESAFE_API_KEY= line in a gitignored
FM_HOME/.env. Two things must hold: (1) that file alone activates the tool, and
(2) the process environment wins over the file.

FM_HOME/.env now contains a DELIBERATELY INVALID placeholder key (not the captain's).

CASE A: key absent from the environment -> the .env line alone must activate the tool.
        The tool is no longer 'off'; it calls the API and, because the placeholder is
        rejected, reports a clean error instead of blocking the intake.
$ env -u TYPESAFE_API_KEY FM_HOME=<sandbox> fm-dispatch-resolve.sh brief.md --project pager
